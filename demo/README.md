# Demo data

`synthetic-android.zip` is a **synthetic** Android file system made for testing. No real person,
device or message is in it. It is generated by `scripts/make_synthetic_android.py`.

What you will find after **Run all**:
| What | Where in Tracelume |
|---|---|
| 3 SMS messages | Artifacts → Messages (conversation view) |
| A chat app database with **3 deleted messages** | Artifacts → Recovered (deleted) records, and the SQL tab |
| 3 photos, 2 with GPS and a time zone | Artifacts → Photos & videos (gallery) and Map |

The launcher copies this file into the `import/` folder, so you can pick it under
*Evidence → From the import folder*.
