# Tracelume brand

| File | Use |
|---|---|
| `mark.svg` | App icon / favicon (64×64 grid) |
| `logo.svg` | Wordmark on dark backgrounds |
| `logo-light.svg` | Wordmark on light backgrounds (e.g. printed reports) |

The mark is a magnifying lens framing three points on a timeline: evidence, events, and findings.

Colours: ink `#0b1220`, slate `#e2e8f0`, teal `#2dd4bf` (primary), amber `#f59e0b` (highlight / tagged).

The logo is released under the same GPL-3.0 licence as the project. Please don't use it in a way that suggests your fork is the official project.
